# P08
SeaDataNet Parameter Disciplines

Terms used to classify SeaDataNet Agreed Parameter Groups to provide topic/theme level terms in a hierarchical parameter discovery interface.

URL: 	[http://vocab.nerc.ac.uk/collection/P08/current/](	http://vocab.nerc.ac.uk/collection/P08/current/)

## Request for new terms and ways to contribute
- Requests for a new P08 can be submitted as [regular issues](https://github.com/nvs-vocabs/P08/issues) in this repository or emailed to vocab.services-at-bodc.ac.uk.

- Reporting errors or suggestions for improving content can be also be submitted as above.
